# Exploratory Area (Temporary / Disposable)

This directory is a sandbox for experimental code, quick prototypes, debugging, and short-lived investigations.

## ⚠️ Important Warning

Nothing in this folder is intended for long-term use, production, or maintenance.

- Code here may be incomplete, broken, or inconsistent.
- Interfaces, structure, and dependencies may change or be deleted at any time.
- There are no stability guarantees.
- Nothing in this folder should be treated as part of the main project.

## 🚫 Not for Long-Term Storage

Do not rely on anything in this directory. If something becomes useful or stable, it **must be moved out** into the appropriate production or library structure.

## 🧹 Cleanup Policy

This folder should be regularly cleaned. Anything not actively being worked on should be removed without concern for backward compatibility.

---

If you're unsure whether something belongs here, it probably doesn't.
